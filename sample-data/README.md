# sample-data 使用约定

本目录内容均为**合成测试数据，不含任何真实用户内容**。

## 为什么存在这个目录

开发协作、UI 联调、自动化测试都需要一些"看起来像真实截图"的样例图片。为避免开发者手滑把自己手机上的真实截图当作调试素材提交，约定：

- 所有调试用的示例数据统一放在本目录下，与运行时真实写入的 `HyperSS/projects/` 目录（已被 `.gitignore` 排除）在物理路径上完全隔离。
- 本目录内的图片必须是**合成 / 占位内容**（纯色色块 + 假文本渲染，或明确可自由使用的开源素材）。
- 严禁放入任何人手机上的真实截图，即使做了打码处理也不行。

## 添加示例数据

1. 在 `sample-data/` 下按用途建立子目录（如 `ui-preview/`、`stitch-fixtures/`）。
2. 图片使用合成内容生成，文件名表达用途即可。
3. 如需要生成占位长图，可参考 `rust-core/hyperss-core` 的测试代码中使用纯色条带合成的方式。

## 运行时真实数据

应用运行时写入的截图数据位于设备应用专属目录（Android `getExternalFilesDir()` 下的 `HyperSS/`），不会进入本目录，也不会进入 Git 历史。
